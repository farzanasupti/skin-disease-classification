# Skin disease classification with duplicate-aware validation and uncertainty-based referral

Code for the paper *Ensemble Deep Learning for Skin Disease Classification with Duplicate-Aware Validation and Uncertainty-Based Referral* (in preparation).

The study compares a compact custom CNN with seven frozen ImageNet backbones (VGG16, ResNet50, MobileNetV2, EfficientNetB0, DenseNet121, InceptionV3, Xception) on five skin conditions: acne, hyperpigmentation, nail psoriasis, Stevens–Johnson syndrome/toxic epidermal necrolysis (SJS-TEN) and vitiligo. Three things are designed to make the reported numbers trustworthy:

- **Duplicate-aware splits.** The dataset has no patient identifiers and was collected partly from online sources. Images are therefore grouped by source filename *and* by perceptual hash before splitting, and a group never crosses the test set or a cross-validation fold.
- **Selection on validation only.** Five-fold grouped cross-validation chooses the best model and the ensemble members. The held-out test set is used only for reporting.
- **Uncertainty that is measured, not asserted.** Monte Carlo dropout runs at inference, and we report calibration (ECE, NLL, Brier), how well uncertainty flags errors, and accuracy after referring the most uncertain cases.

Every number, table and figure in the manuscript is generated by `scripts/analyze.py` from saved predictions. None is typed by hand.

## Data

*Skin Disease Classification Dataset*, Mendeley Data, [doi:10.17632/3hckgznc67.1](https://doi.org/10.17632/3hckgznc67.1) (9,548 images, five classes). Download it and point `--data-roots` at the folder(s) holding one sub-folder per class. The images are not redistributed here.

## Running

**On Kaggle (recommended; this is how the paper's results were produced).** Open [`notebooks/kaggle_run.ipynb`](notebooks/kaggle_run.ipynb) and follow the instructions in its first cell. One full run is 8 models × 5 folds. It is resumable, so a run that hits the 12-hour session limit continues where it stopped.

**Anywhere else:**

```bash
pip install -r requirements.txt
export KERAS_BACKEND=tensorflow
python scripts/run_experiment.py --data-roots /path/to/dataset --out-dir outputs --mixed-precision
python scripts/analyze.py --out-dir outputs --paper-dir paper/generated
```

`python scripts/run_experiment.py --help` lists every setting (image size, folds, epochs, L2 strength, MC samples, …). Defaults match the paper.

## Outputs

| Path | Contents |
|---|---|
| `outputs/splits.csv` | Every image with its group, partition and perceptual hash |
| `outputs/grouping_stats.json` | How many duplicates were found and how |
| `outputs/runs/<model>_fold<k>/` | Training history, per-run summary, validation/test probabilities and MC-dropout samples |
| `outputs/results/` | Aggregated metrics, confidence intervals, significance tests (CSV/JSON) |
| `paper/generated/` | LaTeX tables, figures and `numbers.tex` used by the manuscript |

## Tests

```bash
pip install pytest
KERAS_BACKEND=tensorflow pytest -q tests   # torch backend also works
```

The tests check duplicate grouping, leakage-free splitting, per-backbone preprocessing and MC dropout. They also run the whole pipeline on synthetic images, on CPU, in about two minutes.

## Layout

```
src/skinclf/data.py      loading, duplicate grouping, grouped stratified splits
src/skinclf/models.py    CustomCNN, frozen backbones with correct preprocessing, MC dropout
src/skinclf/train.py     training one (model, fold) and saving predictions
src/skinclf/metrics.py   classification, calibration, uncertainty, group bootstrap
src/skinclf/stats.py     Friedman/Nemenyi across folds, Holm-corrected McNemar on test
scripts/                 experiment runner and analysis
notebooks/               Kaggle runner
paper/                   manuscript source
```
